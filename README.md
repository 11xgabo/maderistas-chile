# Maderistas Chile — Madero 10

Beta de un juego web responsive construido con React y Vite. El juego incluye controles táctiles y con teclado, instrucciones, y un reproductor integrado de Spotify.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar para producción

```bash
npm run build
npm run preview
```

El sitio usa imágenes locales en `images/`. El reproductor de Spotify necesita conexión a internet y puede requerir una cuenta.
